# Deviations — index

The deviation log is split by status:

- [DEVIATIONS-UNRESOLVED.md](DEVIATIONS-UNRESOLVED.md) — needs a user decision or a manual read of
  conflicting source material. Check before building in the affected area.
- [DEVIATIONS-IN-PROGRESS.md](DEVIATIONS-IN-PROGRESS.md) — classification decided, correction or
  follow-up not yet landed. Check before starting a related task.
- [DEVIATIONS-RESOLVED.md](DEVIATIONS-RESOLVED.md) — closed. Not needed for day-to-day task work;
  reviewed only in the end-of-project / high-level sweep.

New deviations found while working a task go in **In Progress** or **Unresolved** as appropriate;
move a row to **Resolved** once its correction lands.
